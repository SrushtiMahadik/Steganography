# Steganography
Steganography is the technique of writing hidden messages in such a way that no one apart from the intended recipient knows of the existence of the hidden. Steganography can be used to hide private or sensitive information in Image, Video, Audio and in QR Code.

# 🕵️‍♂️ Steganography Web Application  
A web-based tool for hiding secret messages inside Image, Audio, Video, and QR Code using Steganography techniques.

#📌 What is Steganography?
Steganography is the technique of hiding secret information inside another file in such a way that only the intended recipient knows about it.  
This project allows you to hide and extract secret data securely.

# 🚀 Features
✔️ Hide text inside Images  
✔️ Hide text inside Audio  
✔️ Hide text inside Video  
✔️ Generate QR Code with hidden message  
✔️ Extract hidden message back from media  
✔️ Simple and clean User Interface
